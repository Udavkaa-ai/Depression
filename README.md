# 🚇 Метро Москвы — карта по интересам

Интерактивная карта московского метро с поиском станций по категории мест
рядом. Нажимаешь на категорию (кафе, торговые центры, спорт, развлечения…) —
на карте подсвечиваются **только те станции, рядом с которыми (в радиусе 1 км)
есть искомые места**. Остальные приглушаются.

![пример](docs/preview.png)

## Как это работает

- Карта — [Leaflet](https://leafletjs.com/) + тёмные тайлы CARTO.
- Данные о станциях метро и о местах берутся **вживую** из OpenStreetMap
  через [Overpass API](https://overpass-api.de/) — без ключей и регистрации.
- При выборе категории приложение:
  1. запрашивает у Overpass все объекты этой категории по Москве;
  2. строит пространственный индекс (сетка) по этим точкам;
  3. для каждой станции честно считает по формуле гаверсинуса, сколько мест
     попадает в заданный радиус;
  4. подсвечивает станции, где мест > 0, и показывает список с количеством.

Радиус настраивается ползунком (300–2000 м). Клик по станции показывает круг
радиуса и число мест. Галочка «Показывать места» рисует сами точки на карте.

## Категории

Кафе · Рестораны · Фастфуд · Бары · Торговые центры · Развлечения (кино,
театры, клубы) · Спорт (фитнес, стадионы, бассейны, площадки) · Парки · Музеи ·
Супермаркеты · Аптеки.

Категории описаны в массиве `CATEGORIES` в `index.html` — добавить новую
можно одной строкой с [OSM-тегами](https://wiki.openstreetmap.org/wiki/Map_features).

## Запуск

Это статический сайт из одного файла. Нужен доступ в интернет (Overpass + CDN
Leaflet/CARTO).

**Локально** — просто открой `index.html` в браузере. Если браузер блокирует
запросы из `file://`, подними локальный сервер:

```bash
python3 -m http.server 8000
# затем открой http://localhost:8000
```

**GitHub Pages** — включи Pages для ветки, `index.html` в корне отдаётся сам.

## Замечания

- Полнота данных зависит от OpenStreetMap. Для более точных данных можно позже
  подключить API Яндекса или 2ГИС (потребуется ключ).
- Список станций кэшируется в `localStorage` на 30 дней, чтобы не запрашивать
  его каждый раз.
- Публичный Overpass иногда бывает загружен — в коде есть запасные эндпоинты,
  при ошибке просто повтори выбор категории.
